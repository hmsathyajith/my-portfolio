# Sathyajith Saliya — Portfolio

Personal portfolio site for H.M Sathyajith Saliya Ariyakumara, Senior Software Engineer.

Built with plain HTML, CSS and JavaScript (no build step) — animated hero with a
particle network, scroll-reveal sections, a typewriter role rotator, animated stat
counters and skill bars, and a light/dark theme toggle.

## Structure

- `index.html` — page content
- `assets/css/style.css` — styling and theme tokens
- `assets/js/main.js` — interactions (theme toggle, reveal animations, typewriter, particles)
- `assets/cv/` — downloadable CV
- `docs/` — source CV

## Running locally

Just open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Deployment

Hosted with GitHub Pages from the `main` branch.
